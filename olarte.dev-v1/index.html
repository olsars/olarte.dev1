NightSentinel is an AI-powered security monitoring system that combines NVIDIA Jetson computer vision, YOLO person detection and tracking, a Python FastAPI backend, a React dashboard, and Arduino hardware to detect and respond to restricted-zone activity in real time.

TrailBuddy

TrailBuddy is a Raspberry Pi-powered virtual pet and GPS hiking companion that combines embedded hardware, real-time GPS tracking, and an interactive web application. Built with Python, FastAPI, SQLite, and React, the system records walking routes, stores GPS data, and allows users to view their adventures while caring for a virtual pet.
